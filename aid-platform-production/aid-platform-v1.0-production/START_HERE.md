# Aid Platform - Production Package v1.0

## 🚀 Quick Start (5 Minutes)

### Step 1: Install Prerequisites
1. **Git for Windows**: https://git-scm.com/download/win
2. **Node.js v22+**: https://nodejs.org/

### Step 2: Install Dependencies
Open Git Bash in this folder and run:
```bash
cd frontend
npm install -g pnpm
pnpm install
```

### Step 3: Start the Application
Double-click: `start-aid-app.sh` (or run in Git Bash)

### Step 4: Access the App
Open browser to: **http://localhost:5173**

Default login:
- Email: `admin@example.com`  
- Password: `admin123`

⚠️ **Change password after first login!**

### Step 5: Setup Automation (Recommended)
Run as Administrator:
1. `setup_auto_update.bat` - Daily updates at 3 AM
2. `setup_auto_backup.bat` - Hourly backups
